# Student Information Card

- A simple program that displays the student personal information, including the name, hometown, and favorite hobby. This assignment shows the appropriate formatting in Python along with demonstrating Git Workflow.

## Features

- Display student name (original)
- Display major and graduation year (original)
- Display email (new)
- Display hometown (new)
- Display favorite hobby (new)
- Comments that organized the program (new)

## Technologies Used

- Python 3.14.3
- Visual Studio Code
- Git for version control
- GitHub for repository hosting

## Installation and Setup

### Prerequisites
- Python (updated and installed on your computer+
- Visual Studio, Git Bash and Github installed

### Steps to Run
- Open git bash, run the code
   - git clone "https://github.com/cjspersona/CPSC4205_GitWorkflow.git"
   - Next, cd CPSC4205_GitWorkflow
- Open Visual Studio Code or Python and edit the file from there

## Usage

- Simply run the program to see the formatted student information card.

### Sample Output:
```
==========================================

Name: CJ Hickson

Major: Information Technology

Graduation Year: 2026

Email📧: hickson_cory@columbusstate.edu

Hometown🏠: Roberta, Ga

FavoriteHobby: Playing video games or working out

==========================================
```
